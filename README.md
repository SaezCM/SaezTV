# SáezTV

Reproductor IPTV para **Android TV, Fire TV y móviles Android**.

SáezTV es solo un reproductor: **no incluye canales, películas ni listas**. Cada usuario añade su propia lista (Xtream Codes o enlace m3u).

## Descargar

**Última versión:** [SaezTV.apk](../../releases/latest/download/SaezTV.apk)

### En la tele con la app Downloader

1. Instala **Downloader** (de AFTVnews) desde la tienda de tu tele.
2. Permite que Downloader instale apps: *Ajustes → Mi Fire TV / Dispositivo → Opciones para desarrolladores → Instalar apps desconocidas → Downloader → Activado*.
3. Abre Downloader y escribe el código:

   ```
   5684170
   ```

   (o la dirección completa: `https://github.com/SaezCM/SaezTV/releases/latest/download/SaezTV.apk`)

4. Pulsa **Go**, espera a que se descargue y pulsa **Instalar**.

### En el móvil

Abre el enlace de descarga de arriba desde el navegador del móvil y, al terminar, abre el archivo para instalarlo (acepta "Instalar apps de origen desconocido" si te lo pide).

## Actualizar

Repite los mismos pasos con la misma dirección: siempre descarga la última versión y se instala encima sin perder tus listas ni tu historial.
